# LuxArb Demo

Cross-platform **price comparison** for pre-owned luxury bags and watches.

This static demo shows how similar authenticated listings can differ across major resale platforms (The RealReal, Fashionphile, Rebag, Vestiaire Collective, Chrono24). Sample products and prices are **illustrative only** — not live inventory or financial advice.

**Default language:** English, with an on-page language switcher.

**Contact:** frank-cps@mail.grokbot.com

**Live demo:** https://fransyun.github.io/luxarb-demo/

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Home — about, how it works, methodology, featured samples |
| `compare.html` | Five sample comparison cards |
| `product-*.html` | Product detail templates |
| `disclaimer.html` | Condition, fees, authenticity, and commission disclosure |
